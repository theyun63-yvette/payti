# payti · 买点人设

一个轻量的消费人格测评网页：44道生活场景题，14类消费人格，每次有效提交给出一个结果。

## 在线使用

[打开消费人格测试](https://theyun63-yvette.github.io/payti/)

支持手机和电脑浏览器。五档选择、点选后自动切题、返回修改、刷新续答、唯一人格结果、PNG分享卡和试测记录下载。

## 数据与版本

- 当前题库与计算规则：v0.7。
- 答案和反馈保存在答题者自己的浏览器；网站没有服务器端答卷收集，也不接入资金账户。
- 原12类按三道直接证据题判断；无特定模式得到支持时为“按需营业”，全部排序条件最终并列时为“多线程买家”。
- 四个消费心理维度独立计算，不参与人格排序。
- 部分作答不补分，结果和分享卡注明已答题数。零作答不能提交。
- 这是一份娱乐性消费画像试测，尚未完成真人测量验证，不提供理财建议。

## 本地运行与更新

无需安装依赖或构建。下载仓库后打开 index.html，或在此目录运行 `python3 -m http.server 8000`，访问 `http://localhost:8000/`。

GitHub Pages使用 main 分支的根目录。更新网页后提交到 main，等待 Pages 发布完成即可。

## 验证

网页计算与Python v0.7参考实现逐字段核对21,658组构造答卷，通过，涵盖14类结果、排序与同分分支、缺失值和反向计分。已实测44题完整流程、改答、刷新恢复、全中立、最终并列、部分作答、PNG及JSON下载。以上属于程序验证，不能替代真人测量验证。
