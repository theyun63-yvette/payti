# payti · 买点人设

**v0.10：22道生活场景题、14种消费人格、四个消费切面。**

[打开消费人格测试](https://theyun63-yvette.github.io/payti/)

## 使用方式

五档圆圈表示两端倾向，中间代表中立。点选自动进入下一题，可返回修改、刷新续答。22题均从五档中选择答案后，可以查看唯一结果并保存分享卡。不会追加题目。

场景覆盖换新、二手、分期、奖励、省事、后续成本、搭配、送礼、租买、囤货、凑单、退货、闲置、退改等。问题以已确认的v0.10题库为准。

## 计分和文案

每个人格由两个明确场景共同支持，两题等权；四个消费切面按各自题组另行汇总，不由主人格推导。完整规则见 [计分与边界规则](docs/v0.10/03-计分与边界规则.md)。

每份有效答卷只展示一个人格。结果页和分享卡使用同一个计分结果中的名称与正文；内部支持等级、参考分配和技术决胜标记保留，不作为用户界面提示。支持充分时使用第二人称人格介绍；其他情况下使用该模式的概括，不冒称确认了未报告的行为。

50/50保持真实值；全中立、场景间方向相反、单题依据和无数据分别处理。无数据不生成百分比或方向。比例是答案的换算，不是准确率或人群百分位。

## 人物与分享

14张透明背景PNG通过N01—N14明确绑定。6张沿用并复核，8张为新版生成；安心买家的背景清理后采用修订图。图片及来源映射见 `assets/personas/manifest.json`。

结果页展开四个切面的解释及对应选择。分享PNG包括人物、人格正文和四维概览，按文字实际长度排版；可下载、复制文字，或在浏览器支持时调用系统分享。

## 记录与版本

唯一生产计分程序为 `engine.js`。无需登录，不接入资金账户，不向服务器集中发送答卷。

本机记录键为 `payti:0.10:answers`，表单标识为 `payti-22-2026-11-05`。保存原始屏幕位置、当前题号和本机备注。早期v0.10记录中的非数值回答恢复为待答题，原记录先另存备份；补齐答案后才能查看或分享结果。v0.9等旧答卷单独保留，不能转换成新题答案。异常新版记录先隔离保留，再从新答卷开始。

## 文件与本地运行

- `index.html`、`style.css`、`app.js`：页面与交互。
- `data.js`：题库、文案、图片映射；`spec.json`：冻结的原始规则。
- `engine.js`：与离线v0.10完全相同的计分实现。
- `assets/personas/`：14张人物图；`docs/v0.10/`：当前题目和规则说明。

在本目录运行 `python3 -m http.server 8000`，浏览器打开 `http://localhost:8000/`。GitHub Pages使用main分支根目录，发布须在本地预览确认后进行。

根目录05、06、08开头的Markdown文件为v0.7历史资料，不是当前规则。旧网页保留在Git提交历史。自动化检查用于验证程序与页面，不代表真人心理测量有效性。

[网页交互修订0.10.1](docs/v0.10/09-网页五档必答修订.md)：全部22题必答，计分公式与题目内容不变。离线引擎保留历史缺失状态的解析能力，网页不提供这些回答入口，也不接受不完整答卷完成或分享。
