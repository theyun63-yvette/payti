# payti · 买点人设

**v0.9：50道生活场景题、14种消费人格、四维独立解读。**

[打开消费人格测试](https://theyun63-yvette.github.io/payti/)

## 怎么使用

首页直接进入题目。五档圆圈从左到右表示倾向，中间是中立；“无相关经历”“跳过”单独保存。点选自动进入下一题，最后一题处理后点击“看看我的消费人格”。可随时通过题目目录回看修改、暂存和续答。

50题必须全部处理，且至少一道人格核心题提供数值答案。只有四维答案、全部跳过或未完成的答卷不能展示完成结果或分享。

## 本版内容

- 每个人格包含核心倾向、实际行为、补充判别3题，共42题；四维另有8题，固定交错排列。
- 接入14张人物插画和最新人格介绍；测评传教士使用修正双臂后的v2图。
- 四维全部展开，展示真实百分比、一个方向字母和180—220字解读。4,032段解读覆盖正常方向、中立、相反和缺失等组合。
- 移除开始说明页、结束总览、人格预告卡、旧进度条与结果反馈区，简化答题流程。
- 分享卡包含对应人物、人格名称、特征短句和四维概览。支持保存PNG、复制文字，以及浏览器支持时的系统图片分享。

## 计分与结果

核心倾向40%、实际行为60%，构成统一主分。补充题不进入主分，只处理主分并列。核心任一答案明确否定时，排除该类型的普通匹配资格。四维独立计算，不参与主人格排名。

每份有效答卷只展示一个主人格，统一使用“你的消费人格”、完整性格介绍及对应插画。结果页、四维解读和分享卡不再显示“参考类型”或核心证据不足的提示。底层评分、同分与唯一分类规则保持不变；同样的答案保持稳定结果，不随机换类型。

四维50/50保持真实数值并解释字母同分依据。缺失不补中立，无数据不生成百分比或方向。比例是回答的换算，不是概率或准确率。

## 隐私与版本

答案在浏览器内计算，没有服务器端答卷收集，也不接入资金账户。新版使用独立的本机记录键 `payti:0.9:answers`，保存原始屏幕位置、缺失状态、进度与自愿填写的单题备注。旧版记录单独保留，不自动转换为新版答案。

这是一份供自我观察和交流的消费画像测试，尚未完成真人心理测量验证，不提供心理诊断或理财建议。

## 本地运行与验证

无需安装依赖或构建。在仓库根目录运行：

```sh
python3 -m http.server 8000
```

访问 `http://localhost:8000/`。GitHub Pages从main分支根目录发布。
